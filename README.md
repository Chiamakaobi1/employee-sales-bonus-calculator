# Employee Sales Bonus Calculator

A Python project that calculates employee bonuses based on monthly sales performance.

## How it works
The program takes an employee's total sales amount and calculates their bonus using these tiers:
- ₦1,000,000+ sales = 10% bonus
- ₦500,000 - ₦999,999 sales = 7% bonus
- ₦250,000 - ₦499,999 sales = 5% bonus  
- Below ₦250,000 sales = 2% bonus

## How to run
1. Run the file: `python bonus_calculator.py`
2. Enter the employee's sales amount
3. The program will display the sales amount and bonus earned
